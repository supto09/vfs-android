# Context Index (Load-On-Demand)

This folder contains lightweight project indexes intended to reduce token usage.

Usage policy
- Do not load these files by default at session start.
- Open only the specific file needed for the current task.
- Avoid opening multiple files unless necessary.

Files
- `PROJECT_MAP.md`: high-level architecture and flows.
- `FILES_OF_INTEREST.md`: curated list of important files.
- `INDEX.md`: full file-by-file index (open only when needed).
- `BRIEF.md`: task-specific mini-briefs to avoid loading more context.
- `CHANGELOG.md`: minimal recent changes summary.

Maintenance
- Update these files when project structure or major flows change.
